# Code of conduct

We are committed to a respectful, technically rigorous community. Be kind,
assume good intent, critique ideas rather than people, and make room for
beginners to ask precise questions. Harassment, discrimination, threats,
doxxing and unsafe pressure are not accepted.

Maintainers may edit or remove harmful contributions and restrict participation
when needed. Report conduct concerns privately through the repository owner's
GitHub profile. For security or safety defects, use the process in
[`SECURITY.md`](SECURITY.md) instead of a public issue.
