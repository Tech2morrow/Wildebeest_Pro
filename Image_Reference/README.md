# Images and media

Place publishable assembly photos, wiring close-ups, screenshots and test plots
here. Remove GPS coordinates and private surroundings before committing media.
Use descriptive names such as `rear-harness-rev-a.jpg` and include license/source
information when the image was not created for this project.

Repository brand artwork lives under [`assets/`](../assets/). The operator UI
lives under [`dashboard/`](../dashboard/).
