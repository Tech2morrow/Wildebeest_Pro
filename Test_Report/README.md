# Test evidence

Generated logs and reports are not treated as proof unless they identify the
commit, configuration, equipment and test level. Use these evidence levels:

1. static/unit test
2. protocol mock
3. physics simulation
4. current-limited bench test
5. raised-wheel hardware test
6. bounded floor test

Do not commit private maps, raw GPS tracks or camera data. The acceptance
procedure and report template are in [`docs/testing.md`](../docs/testing.md).
